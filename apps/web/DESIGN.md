# 追分页面设计

方向：苹果式的清晰层次——安静的底色、统一的圆角、大而清楚的数字，视觉的主角只有两处：给分时的扑克牌，和结束后的战绩海报。日常界面不用装饰描边和持续动效。

## 尺寸和颜色（都在 `app/assets/main.css` 顶部的变量里）

- 圆角四档：`--r-s` 10（小控件）、`--r-m` 14（按钮、输入框）、`--r-l` 22（卡片）、`--r-xl` 28（大卡片、弹窗）。不要再写别的圆角。
- 间距用 4 的倍数；卡片内边距电脑 24–28、手机 18–20；卡片之间 16–20。
- 白天：雾灰 `#f5f5f7` 底、纸白卡片、墨色 `#1d1d1f` 文字、三级灰 `--muted` / `--faint`、台球绿 `#1f6a51` 只用于主操作和「我」。
- 夜间：炭绿底、墨绿记分区、暖金主按钮；扑克牌和二维码保持白底。
- 输赢：赢用绿、输用红，都只出现在小胶囊（`.delta-chip`）和记录里，不大面积铺色。
- 数字（比分、分值、房间号）用圆体数字 `--font-num`，等宽对齐。
- 卡片不加阴影，靠底色区分；只有弹窗、提示这类浮层有阴影。

## 部件

- 按钮：主按钮 `.primary`（一屏一个）、次按钮 `.secondary`、文字按钮 `.text-button`、小胶囊 `.pill`（工具栏、筛选）。危险操作在工具栏里是浅红胶囊，确认弹窗里才是实心红。
- 分段选择 `.tabs` / `.mode-picker`：灰色轨道 + 白色滑块，用于「创建/加入」「双人/三人」「全部/单机/联机」和单机里选给分的人。
- 比分卡 `.player-card`：头像、昵称、大数字、本场输赢胶囊，全部居中对齐。
- 名次列表 `RankList`：按本场输赢排序，赢家带皇冠。历史列表、历史详情共用。
- 记分记录 `EventList`：一行一笔，「谁 给 谁」+ 类型标签 + 分值。
- 弹窗：电脑居中、手机从底部滑出；给分提示放在屏幕上方，不挡底部按钮。
- 选收分人 `RecipientOptions`：一行一位球友，头像、昵称、现在的积分，右边是这一笔的「+N」。
- 提示条两种：绿色 `.resume-banner`（首页「回到这一桌 / 继续记分」），金色 `.follow-up`（大金、黄金9 记完一位输家后提示另一位也给）。都是一句话 + 一个动作，可以忽略。
- 邀请卡片 `InvitePanel`：等人时直接显示二维码、房间号、复制链接；手机上排在最前，电脑上在右侧。

## 页面

- 首页：左边一句话和球台，右边一张卡片完成「创建 / 加入」；单机入口和历史入口放在卡片底部。通过邀请链接进来时只显示「填昵称 → 加入」。会记住上次的昵称和人数。
- 房间：顶部一行小工具（首页、历史对局、结束本场），下面是房间名和一行信息，然后是比分、给分、记录。电脑上记录在右侧。
- 历史对局：居中单列。有两场以上时顶部是「累计输赢」。按天分组（今天、昨天、几月几日周几），顶部筛选条吸顶；「按日期找」打开日历，只有打过球的日子能点。
- 历史详情：一句话结论（谁赢了多少）+ 名次 + 三个统计数字 + 生成战绩海报，右侧是记录。
- 战绩海报（`utils/poster.ts`）：深绿球台 + 金色赢家，画在 canvas 上再用图片显示。微信里不能下载文件，所以提示长按保存；普通浏览器有「分享给球友」「保存图片」。

## 递牌动画

确认后的事件驱动抽牌、弧线移动、落牌；收分者回弹，付分者收缩，第三人看到相同流向。刷新不重播，版本去重，动画排队并限制积压；隐藏页面停止动画，减少动态效果时只显示文字。比分始终以服务端最新值为准。

牌面只是本次分数的表现：A=1，2–10=面值，J/Q/K=15。暂不建立真实手牌库存，不做找零，不阻止负分。组合牌点数之和必须等于本次转移分数。

给分入口是一排五张扑克牌：犯规 A、普胜 4、小金 7、大金 10、黄金9 4。不同花色区分规则；按钮与递牌动画共用 PlayingCard。自定义分值分解成合法面值，最多展示三张叠牌。320px 手机宽度下按钮仍至少 44px。

## 白天／夜间

顶部切换并保存至本机。首次跟随系统；用户手动选择后优先保留。主题初始化脚本在首次绘制前读取选择，避免夜间刷新闪白。手机状态栏颜色跟着页面底色，改 `--page` 时要同时改 `public/theme-init.js`、`app.vue` 和 `public/manifest.webmanifest`。

## 极端情况

改排版后用这些数据看一遍：12 个字的昵称、24 个字的房间名、五位数的积分（初始 10000）、负分、打平、320 宽的手机。昵称换行时三张比分卡的分数要对齐在一条线上；四位、五位数的积分在手机上逐级缩小字号。
