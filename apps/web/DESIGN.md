# 追分页面设计

方向：苹果式清晰层次与真实递牌。视觉的主角是给分时的扑克牌，日常界面安静、易读；不使用装饰描边或持续特效。

配色：雾灰 #f5f5f7、纸白 #ffffff、墨色 #1d1d1f、台球绿 #23745e、收分金 #c08a30、失分红 #b54c48。系统中文字体与系统等宽数字，不加载外部字体。标题左对齐，比分居中，普通内容用留白分组，浮层才使用明显阴影。

手机布局：
```
返回首页                    结束本场
房间名 / 房间号              邀请
[球友 / 比分] [我 / 比分] [球友 / 比分]
          递牌动画区域（浮层，不拦截操作）
我来给分 / 大按钮
本场记录
```
电脑把记录移到右侧。按钮至少 48px，保留焦点与底部安全区。

确认后的事件驱动抽牌、弧线移动、落牌；收分者回弹，付分者收缩，第三人看到相同流向。刷新不重播，版本去重，动画排队并限制积压；隐藏页面停止动画，减少动态效果时只显示文字。比分始终以服务端最新值为准。

牌面只是本次分数的表现：A=1，2–10=面值，J/Q/K=15。暂不建立真实手牌库存，不做找零，不阻止负分。组合牌点数之和必须等于本次转移分数。

设计自查：避免把每个区域做成同样的卡片；取消大面积深绿，绿仅用于主操作和自己的标识；不增加无关礼花，将动效集中到有来源、有去向的递牌。
