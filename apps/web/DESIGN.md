# 追分页面设计

追分主要在球桌旁用手机操作。界面先让球友看清比分，再让输家快速给分；电脑端利用更宽的空间并排展示开局入口和记录。

| 用途 | 颜色 |
| --- | --- |
| 页面底色 | `#eef3f4` |
| 正文 | `#17383b` |
| 主按钮与状态 | `#12574f` |
| 记分板 | `#174f4a` |
| 球号与大金强调 | `#edce70` |
| 关闭、结束等危险操作 | `#ad443b` |

正文使用系统中文字体，积分数字优先使用等宽数字的系统字体。移动端输入框保持至少 16px 字号，常用按钮至少 48px 高；弹窗从底部出现并避开系统安全区域。

手机首页顺序：一句介绍 → 创建／加入房间 → 最近房间。手机房间顺序：返回与结束 → 房间名和状态 → 三人比分 → 给分 → 记录。开局设置可展开，开局按钮始终在设置前。电脑端房间记录与比分并排。

特殊情况：长房间名允许换行；长积分缩小字号；窄屏不会出现横向滚动；弹窗打开时限制背景滚动和键盘焦点，关闭后还原。
