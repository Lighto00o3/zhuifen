# 追分双方案交互预览

目标：让球友在手机上比较清爽球房与夜场球桌，先选择方向，再迁移真实房间。独立 /design-preview 路由，仅浏览器模拟状态，不连接 API，不读写真实房间和会话。

配色：清爽球房使用纸白 #ffffff、雾灰 #f4f5f4、墨色 #202722、台球绿 #28654c、收分金 #d7b76d、提示灰 #727a74。夜场球桌使用炭灰 #202421、桌面绿 #254b3b、柔白 #f4f3eb、金色 #d7b76d、浅绿 #aac3b0、暗灰 #303832。

字体：系统中文字体；积分使用系统等宽数字，自己积分 76px、球友积分 32px；牌角使用 Georgia，模仿印刷扑克。避免加载外部字体。

手机布局：
```
设计预览 · 模拟数据       返回正式版
[ 清爽球房 | 夜场球桌 ]
周末球友局                 三人追分
    [小林 94]          [小陈 94]
              我的积分
                112
             本场 +12
        A    4    7    10  （选择给分）
最近一笔 / 历史记录
[ 试试收分 +7 ] [ 重置体验 ]
```
桌面左侧说明设计取舍，右侧为可实际操作的手机宽度体验。手机不套假手机边框，优先保证操作面积。

交互：点击分数牌 → 底部原生 dialog 选收分人 → 卡牌从自己飞向目标 → 双方积分更新；试试收分从小林飞向自己。收分多一次轻弹与暖光，失分克制下沉。忙时防止重复模拟；对话框支持 Escape、焦点约束和恢复；减少动态效果改用即时结果。可查看记录、撤销与重置。主题切换保留模拟比分，URL 查询参数支持直接分享两套风格。

自查：取消等宽三张大积分卡，把自己的积分作为主角；牌是真正可点的给分入口；金色只服务于九号球与收分，界面不放无关礼花和描边。重点比较配色、层级和给分手感，不修改线上正式 UI。
